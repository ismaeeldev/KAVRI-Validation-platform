# KAVRI Validation Platform

The KAVRI Validation Platform is a secure, responsive Next.js application built to facilitate transparent product validation workflows for athletic equipment (pickleball paddles). It features a secure Owner admin dashboard, a secure mobile-first Tester portal, and an ultra-polished public landing page showcasing verified on-court testing progress, honest metrics, and updates timeline feed.

## Key Features

1. **Owner Workspace**: Secure management of suppliers, products, revisions, physical samples, triage reviews, tester approvals, and validation assignments.
2. **Tester Workspace**: Mobile-first portal accessible to active, approved testers. Testers can securely view assigned briefs, public specifications, and acknowledge validations.
3. **Public Workspace**: Premium "testing in the open" page detailing approved spec sheets, honest build log feed, aggregate metrics, and waitlist follow signup.
